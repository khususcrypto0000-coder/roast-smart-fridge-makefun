A one-line roast of a smart fridge for the make.fun bounty **"Roast the Smart Fridge: One Line, Best Laugh Wins"** — a $2 bounty (1st $0.91 / 2nd $0.64 / 3rd $0.45), free to enter.

The roast targets the fridge's "smart" features — Wi-Fi, a touchscreen, and a 3 a.m. firmware update — while it still fails at its one real job: staying cold.

## Run it

```bash
python3 main.py
```

This writes a single line (1–160 characters, no trailing newline) to `/output/entry.txt`.

## Entry

> My smart fridge has Wi-Fi, a touchscreen, and a 3 a.m. firmware update, but the one feature it never got was staying cold.
